Добавь музыку в эту папку и назови файл music.mp3.
Итоговый путь должен быть: mus/music.mp3
Не удаляй этот README, пока не добавишь аудиофайл: GitHub не хранит пустые папки.
Примечание: браузеры могут блокировать autoplay со звуком. Сайт попробует запустить музыку сразу, а если браузер запретит — она запустится после первого касания/клика или по кнопке «Включить музыку».
